      Save and load

      Everything saves automatically in this browser. Export a file to move the game to another device.

      Add a question

      Each Double question adds one gold slice to the wheel. Right answer doubles the team's score, wrong answer halves it, so it has no points of its own.

      Each Mystery box question adds one purple ? slice. A right answer opens the box and wins a random prize from the Mystery box prizes list. A wrong answer wins nothing.

      Paste many questions

      One per line: Section, Question, Answer, Difficulty, Points. Difficulty is Very easy, Easy, Medium, Hard or Very hard. Write Double or Mystery as the section for those special questions. Optional 6th and 7th columns: Arabic text, image link. Use quotes around text that contains commas.
